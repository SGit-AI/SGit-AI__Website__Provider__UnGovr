No analytics. No cookies. No third-party fonts, scripts or CDN — every byte of this site is served from this domain. Every number was computed at the command line against bytes whose sha256 is published in the retrieval log, and compiled in. Exactly one page opens a network connection — the vault page, to dev.vault.sgraph.ai, to run the vault live from its published read key. Every other page fetches nothing, and a build check holds that line.
